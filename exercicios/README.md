# Exercícios – Linguagem de Programação I

Esta pasta reúne os exercícios desenvolvidos durante as aulas da disciplina de Linguagem de Programação I da FATEC São Bernardo do Campo.

## Objetivo

Praticar os conceitos fundamentais da linguagem Python, incluindo:

- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Listas e dicionários
- Modularização
- Resolução de problemas utilizando lógica de programação
